The problem we solve

Laptop closes · agent crashes · model switches · person leaves → state survives in the file, verified facts degrade honestly at the machine boundary.
1Agent A works — the task's goal, current state, verified facts, decisions, next steps live in a versioned Passport.
2pack — seals state + luggage into one portable file. Machine-scoped facts are marked unproven at pack time. Every pack is logged to an outbox with a snapshot stub.
3Agent B = Gemini lands the file — reads the passport, answers open asks, executes the next step via ADK tools, checkpoints back to Firestore.
4Repack & send back — receipts merge into the original passport (land --into); Agent C (any harness) continues. Never from zero.
